# 측정

파이프라인을 고쳤을 때 나아졌는지 판단하려면 사이클마다 아래를 기록한다.
숫자가 없으면 "잘 되는 것 같다"밖에 말할 수 없다.

## 기록 항목

| 항목 | 의미 |
|------|------|
| 사람 개입 횟수 | 목표는 2회 (재현 승인, 제출). 이게 핵심 지표 |
| CONFIRMED → PASS 생존율 | 낮으면 S1이 오탐을 많이 만든다 |
| 게이트별 탈락 | 어느 게이트에서 가장 많이 걸리나 = S1 프롬프트의 약점 |
| NEEDS_REPRO 발생 | G7이 실제로 일하고 있는지 |
| 교차 검토 라운드 수 | 3 초과면 프로토콜 문제 |
| 검토 지적 중 REJECTED 비율 | 0%면 검토자 말을 그냥 받고 있다는 뜻 (위험) |
| 재현 반복 횟수 | 2회 초과면 S0의 설정 사전조사(P0-5)가 부실했다 |
| 워커 계약 위반 | 커밋 누락 / STATE.md 미갱신 / 산출물 위치 이탈 |
| PASS 1건당 소요 시간 | |
